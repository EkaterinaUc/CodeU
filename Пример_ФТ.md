# Создание проекта

## ФТ-70 Авторизованный пользователь должен иметь возможность создать проект, заполнив форму:

- название *(обязательное)*;
- краткое публичное описание *(обязательное)*;
- полное описание *(обязательное)*;
- местоположение;
- теги *(обязательное)*;
- требуемые роли / участники;
- количество участников;
- опция «ищу участников» *(обязательное)*;
- дата начала;
- дата окончания;
- формат участия *(обязательное)*;
- ссылки.

## ФТ-71 Система должна ограничивать количество проектов на одного автора:
- не более **20 проектов** за всё время *(суммарно во всех статусах)*.
При попытке создать 21-й проект система должна возвращать ошибку:
```text
Превышен общий лимит проектов (максимум 20)
```
- не более **5 активных проектов одновременно**.
Активным считается проект со статусами: `PUBLISHED`, `IN_PROGRESS`

При достижении лимита активных проектов создание нового проекта, который станет активным, невозможно.
Система должна возвращать ошибку:
```text
Превышен лимит активных проектов (максимум 5)
```
Если пользователь создаёт проект, который по своим статусам не является активным *(например: draft, pending_moderation, rejected, hidden, completed, canceled)*, то такой проект:
- учитывается только в общем лимите (20);
- не влияет на лимит активных проектов.

## ФТ-72
Активными считаются проекты:

- в статусах `PUBLISHED` / `IN_PROGRESS`;
- с неархивным состоянием.

## ФТ-73
Система должна отображать дату создания проекта.

## ФТ-74
Проекты должны добавляться в общий список в соответствии с датой создания.

## ФТ-75
Система должна валидировать даты проекта и не позволять вводить аномальные диапазоны.

Рекомендуемое бизнес-ограничение:
- продолжительность проекта не более **36 месяцев** от даты начала.

## ФТ-76
После создания проекта система должна отображать его в разделе:

```text
Мои проекты → Я автор
```

В публичном каталоге проектов проект не отображается до получения статуса:

```text
PUBLISHED
```

*(после одобрения модератором)*.

Если проект сохранён как черновик (`DRAFT`), он также должен быть доступен только автору.

## ФТ-77
Система должна поддерживать отдельный флаг / статус набора участников:

- `RECRUITING_OPEN`
- `RECRUITING_CLOSED`

В API:

- `open`
- `closed`

## ФТ-78
Система должна поддерживать отдельные бизнес-статусы жизненного цикла проекта:

- `IN_PROGRESS` — проект в работе;
- `COMPLETED` — проект завершён;
- `CANCELED` — проект отменён.
