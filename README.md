# CodeU
Web-платформа для IT-специалистов, предназначенная для поиска команды, публикации pet-проектов, взаимодействия участников и обмена знаниями через Q&amp;A-раздел

## 📌 О проекте
Платформа позволяет:
- публиковать и модерировать проекты;
- искать участников в команду;
- откликаться на проекты и отправлять приглашения;
- взаимодействовать через систему вопросов и ответов.
Проект выполнен на этапе системного и бизнес-проектирования и включает полную техническую спецификацию MVP.

## 🧩 Что было сделано
- анализ и формализация бизнес-требований;
- разработка функциональных и нефункциональных требований;
- проектирование REST API;
- разработка API спецификации;
- проектирование ER;
- разработка BPMN диаграмм;
- построение Sequence диаграмм;
- моделирование ролевой системы и матрицы прав доступа;
- проектирование архитектуры платформы.

## 🏗 Архитектура
Проект использует:
- клиент-серверную многослойную архитектуру;
- REST API;
- интеграцию с email-сервисом;
- OAuth-интеграции.

## 🛠 Технологии и инструменты
- BPMN
- ER
- Sequence
- Draw.io
- Miro
- REST API
- JSON
- SQL
